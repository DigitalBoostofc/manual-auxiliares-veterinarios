# Aula de plantão

Treinamento em linguagem simples para **auxiliar veterinário**. A página da aula ensina o que fazer (e o que não fazer). A calculadora é só para conferir a conta depois da ordem do veterinário.

## No ar

- Aula: https://digitalboostofc.github.io/manual-auxiliares-veterinarios/
- Calculadora: https://digitalboostofc.github.io/manual-auxiliares-veterinarios/calculadora.html

## Aviso

Você não escolhe remédio nem dose. Isso é do médico-veterinário (Resolução CFMV nº 1.260/2019).
