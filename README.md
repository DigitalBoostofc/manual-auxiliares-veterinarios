# Manual prático de triagem e emergência

Guia interativo de treinamento para **auxiliares veterinários**, com foco em atendimento inicial, trauma musculoesquelético e manejo terapêutico de rotina (doses, vias, intervalos e tempo de uso sob prescrição do médico-veterinário).

## Abrir no ar

**https://digitalboostofc.github.io/manual-auxiliares-veterinarios/**

## Local

Abra `index.html` no navegador ou sirva a pasta:

```bash
python3 -m http.server 8765
```

## Aviso

Material de treinamento. Prescrição, fluidoterapia, sedação e diagnóstico são exclusivos do médico-veterinário (Resolução CFMV nº 1.260/2019). Não substitui protocolo institucional nem bula.
